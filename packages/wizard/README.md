# @specify-sh/wizard

Add the Specify publisher SDK to a codebase with a coding agent already installed on your machine.

```sh
npx @specify-sh/wizard
```

The wizard uses your coding agent's existing model and authentication. It does not run a model or ask for an API key of its own.

**[Manual setup guide →](https://docs.specify.sh/publishing/get-started)**
